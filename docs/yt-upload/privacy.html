プライバシーポリシー

nippon-youtube-upload(以下「本ツール」)は、運営者本人が自分の YouTube チャンネルへ動画を投稿するための個人用ツールです。

利用する情報

本ツールは YouTube API サービスを利用し、運営者本人が許可した範囲(動画のアップロード)でのみ YouTube アカウントにアクセスします。アクセスに使う認証情報は、動画とサムネイルのアップロード以外には使いません。

収集・保存・共有

本ツールの利用者は運営者本人のみです。本ツールは、運営者以外の人の個人情報を収集・保存しません。取得した情報を第三者に販売・提供・共有することはありません。

アクセスの取り消し

本ツールへの許可は、Google アカウントの設定(https://myaccount.google.com/permissions)からいつでも取り消せます。

関連する規約

本ツールは YouTube API サービスを利用しています。YouTube 利用規約(https://www.youtube.com/t/terms)と Google プライバシーポリシー(https://policies.google.com/privacy)もあわせてご確認ください。
